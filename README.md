# PHONE SWIPES – The Ultimate Idle Clicker Game

A playable 2D pixel-art idle/clicker game built with TypeScript, HTML5 Canvas, Web Audio API, and Vite — designed for desktop & mobile browsers (CrazyGames-ready).

## Features
- **First-Person Pixel-Art Bedroom**: Animated night window, dynamic room decorations, particle bursts, floating bonus drops, and every owned phone in your Phone Farm rendered live on your desk and shelves.
- **Phone Swipes Feed**: Swipe up, click/tap, use mouse wheel, or press `Space`/`W`/`S`/`ArrowUp`/`ArrowDown` to scroll posts, build Combo streaks, trigger **FEVER MODE**, and discover **Common, Uncommon, Rare, Epic, and Legendary** posts with pixel-art illustrations.
- **Deep Progression**:
  - **Phone Upgrades**: Better Screen, Faster Processor, Better Battery, Premium Display, AI Algorithm (with visual hardware shell evolution).
  - **Phone Farm**: Old Android Phone, Basic iPhone, Gaming Phone, Premium Smartphone, Ultra Phone, Quantum Phone — with `1x/10x/MAX` bulk buying & Overclocks.
  - **Automation & Tech**: Auto Scroller, Background Scrolling, Multiple Accounts, AI Scrolling Assistant, Phone Farm Manager, Cloud Engagement Engine, Better WiFi, Faster Internet, Phone Accessories, Charging Stations, Multiple SIM Cards, Premium Algorithms, Advanced Automation.
  - **Customization**: Unlockable Post Categories, OS App Themes, and 10 Room Decorations with passive buffs.
  - **Digital Rebirth (Prestige)**: Ascend at 100K Run DP for permanent Clout Shards and cosmic multipliers.
- **Full Smartphone OS**: Switch between **Swipes**, **Shop**, **Messages** (interactive DM replies), **Awards** (Daily Challenges, 24 Achievements, Milestones), **Stats**, **Rebirth**, and **Settings** (audio sliders, visual toggles, save export/import, hard reset).
- **Zero External Assets**: Procedural pixel-art rendering + procedural Web Audio API sound effects & optional lo-fi chiptune music loop, with automatic `localStorage` saving and offline progress calculation.

## Development & Build

```bash
npm install
npm run dev      # Start local dev server
npm run build    # Typecheck & bundle production build into dist/
npm run preview  # Preview production build
```
